常见问题

Tyria Codex 是什么？

一个非官方的《激战2》助手：你的角色、钱包、交易所、制作、世界首领、Wizard's Vault 和世界地图，还有支持报名的公会活动和 Discord 机器人。这是粉丝项目，免费且没有广告。

在哪里可以使用？

在 Android 上作为应用使用，也可以在任何手机或电脑的浏览器中通过本站的应用页面使用。目前还没有 iPhone 应用：用 Safari 打开浏览器版，点按分享，选择“添加到主屏幕”，它就会像应用一样打开。浏览器版没有通知和世界事件提醒。

我需要 API 密钥吗？需要哪些权限？

游戏数据来自你自己的《激战2》API 密钥，可在 account.arena.net 创建。勾选你想查看的内容：account 始终需要，characters、inventories、wallet、tradingpost 和 guilds 会开启对应的部分。没有密钥时，与你的账号无关的功能仍然可以使用。

我的 API 密钥安全吗？

你的密钥保存在你的设备上（浏览器版则保存在你的浏览器中），只会发送到《激战2》服务器，绝不会发送到我们的服务器。请参阅隐私政策。密钥只能读取数据，你可以随时在 account.arena.net 删除它。

我需要 Tyria Companion 账号吗？

不需要，账号是可选的。公会活动、公会信息和 Discord 机器人需要账号。你通过 Discord 登录来创建它，并可随时在设置或删除账号页面中删除。

关联《激战2》账号时会发生什么？

应用会生成一个有效期为十分钟的令牌，只发送该令牌，绝不发送你的密钥。我们会记录你的账号名、你的公会以及你在其中的职位。如果你是公会会长，同一个令牌会让我们的服务器读取游戏只向会长显示的内容，这样公会成员就能在应用中看到。

为什么我看不到公会的金库、仓库或日志？

游戏只向公会会长显示这些内容。当会长使用 Tyria Companion 并允许时，成员就能在这里看到。会长打开一次应用，就会取回公会数据，并选择成员可见的内容：任何部分都可以隐藏。会显示谁拿了什么的金库、仓库和日志，在会长确认选择之前会保持隐藏。

提示会长尚未共享这些内容。

可能是会长在关联后没有打开过应用，可能是游戏拒绝提供某一部分，也可能是会长将其隐藏了。请让你的会长打开应用，并查看公会页面上的眼睛按钮。

谁算作官员？

由游戏决定。可以邀请、晋升或移出成员，或者编辑职位的职位，就会成为官员，官员可以创建和管理活动。没有人是手动任命的。应用会显示你的公会设定的职位名称，例如 Raid Lead。

如何添加 Discord 机器人？

先把它邀请到你的服务器，然后由拥有“管理服务器”权限的公会会长，在希望显示活动的频道中运行 /tyria connect，并附上公会标签或名称。机器人需要能查看并在该频道发言；使用子区、预定活动、身份组和提醒时，还需要相应的权限，/tyria status 会告诉你缺少什么。

机器人能做什么？

/event create 和 /event weekly 创建活动，玩家通过按钮报名，并选择职业和职责。/event report 添加 Arcdps 报告链接。/tyria settings 设置子区、Discord 活动和提醒。/tyria notify 发布每日成就、新闻和游戏更新。/tyria roles 和 /tyria rankrole 按公会职位授予 Discord 身份组。机器人无法读取消息。

Discord 身份组如何跟随公会职位？

运行 /tyria roles ranks:true。机器人会为你公会的每个职位创建一个没有任何权限的 Discord 身份组，并授予拥有该职位的人。会长的应用取回职位后才会开始；在此之前，成员、官员和会长身份组生效。

为什么浏览器中缺少一些功能？

浏览器版无法使用手机的通知、世界事件提醒或设备上的缓存，因此加载较慢。如果还有其他功能无法使用，请告诉我们。

如何删除我的数据？

设置，然后选择“删除账号”，或使用删除账号页面。你的个人资料、已关联账号、成员身份、报名以及你创建的活动会立即删除。会长取回的数据会在最后一位使用该应用的会长离开时删除。

它与 ArenaNet 有关联吗？

没有。这是粉丝项目。《激战2》及其标志和设计是 NCSOFT Corporation 的商标。

出问题了，向哪里报告？

在 GitHub 上提交 issue，说明你做了什么、看到了什么。附上截图会有帮助。请勿公开你的 API 密钥。
