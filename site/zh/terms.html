服务条款

最后更新：2026年9月30日

本条款是你与运营 Tyria Codex（Android 应用、本站的浏览器版和 Discord 机器人）的人之间的约定。使用它们即表示你同意本条款。如果不同意，请不要使用。

它是什么

Tyria Codex 是一个非官方、免费的《激战2》粉丝项目。它与 ArenaNet 或 NCSOFT 无关联，也未获得其认可。《激战2》及所有相关标志和设计均为 NCSOFT Corporation 的商标或注册商标。游戏数据和图片来自 ArenaNet 公开的《激战2》API，并在其条款允许的范围内使用。使用 Tyria Codex 不会改变你对 ArenaNet、Discord 或其他任何人的权利或义务。

谁可以使用

你必须年满 13 岁，并且达到你所在地可以同意本条款的年龄。你必须遵守《激战2》、Discord 以及你搭配使用的任何其他服务的条款。

你的账号和 API 密钥

  • Tyria Companion 账号是可选的，通过 Discord 登录来创建。你对通过该账号发生的事情负责。
  • 你的 API 密钥属于你。请妥善保管，只使用仅具备你愿意授予的权限的密钥；如果你认为密钥已泄露，请在 account.arena.net 撤销。我们绝不会向你索要密钥。
  • 你只能关联属于你自己的《激战2》账号。

公会和你共享的内容

  • 使用该应用的公会会长，允许我们的服务器读取并保存游戏只向会长显示的公会数据，并按会长的选择向使用该应用的公会成员显示。会长同意这一点，并对其选择显示的内容负责。隐私政策说明了保存什么以及保存多久。
  • 不要为你无权代表的公会关联账号或连接 Discord 服务器。
  • 你添加的公会活动、说明和报告对你的公会可见，如果连接了 Discord 服务器，则对该频道可见。请勿发布任何违法、仇恨、骚扰或误导性的内容，也不要发布任何人的私人信息。

你不得做的事

  • 用它骚扰或冒充他人、发送垃圾信息，或违反游戏或 Discord 的规则。
  • 试图获取不属于你的数据，使服务过载或干扰服务，或绕过其限制。
  • 抓取其数据、转售，或未经询问就用它构建为他人提供相同功能的东西。

内容与移除

你创建的内容仍归你所有。你允许我们按应用的运行方式存储这些内容，并向其面向的人展示。对于违反本条款或损害服务或他人的内容或账号，我们可能会将其移除，并可能断开这样做的 Discord 服务器。你可以随时删除你的账号，请参阅删除账号页面。

可用性与变更

它由一个人在业余时间运营，依赖《激战2》API、Discord 和其他我们无法控制的服务。它可能缓慢、出错、不可用或未经通知就变更，我们也可能终止它或其任何功能。游戏数据的准确性取决于游戏 API 的准确性。

无担保和责任限制

它按现状提供，不保证能够运行、准确或适合你的用途。在法律允许的范围内，对于因使用或无法使用它而造成的损失或损害，包括丢失的报名、错过的活动、错误的数据，或 Discord 机器人做了或没做的事，我们不承担责任。此处的任何内容都不限制你依据消费者保护法享有且无法被限制的权利。
