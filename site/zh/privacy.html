隐私政策

最后更新：2026年9月30日

这是翻译版本。如与英文版本有出入，以英文版本为准。

Tyria Codex 是一个非官方的《激战2》助手。它没有广告和分析工具，不会追踪你，也不会为广告而出售或共享你的数据。本页说明它处理什么、在哪里处理、谁能看到以及保存多久。它涵盖 Android 应用、本站的浏览器版，以及 Discord 机器人。

留在你设备上的内容

你的《激战2》API 密钥、应用用它们下载的游戏数据、你的设置、收藏、关注列表和价格历史，仅保存在你的设备上（浏览器版则保存在你的浏览器中）。应用直接与官方《激战2》API 通信。你的 API 密钥绝不会发送到我们的服务器。在手机上，密钥通过请求头发送给 ArenaNet。浏览器无法对游戏的 API 这样做，因此在浏览器中密钥会放在请求地址里，同样只发送给 ArenaNet。在浏览器中，密钥保存在该浏览器的存储中；清除网站数据即可将其删除。

可选的 Tyria Companion 账号

公会活动、公会信息和 Discord 机器人需要账号，你通过 Discord 登录来创建。以下内容仅在你这样做时适用。

  • 来自 Discord：你的 Discord 用户 ID、名称、头像，以及（如果 Discord 提供）你的电子邮件地址。
  • 你的《激战2》账号：为了关联账号，应用会生成一个有效期为十分钟、只能读取你的账号和你的公会的令牌，并且只发送该令牌。我们会记录你的账号名和 ID、你的公会的名称和标签、你在其中的身份，以及游戏赋予你的职位。令牌只用于这几次请求，不会被保存。
  • 如果你是公会会长：使用同一个十分钟的令牌，我们的服务器还会读取游戏只向公会会长显示的内容，并为公会保存：公会等级、每日消息和成员数量，包含每位成员账号名、职位和加入日期的成员列表，职位以及每个职位的权限，金库、仓库、公会储物、记录谁做了什么的日志、已建造的升级以及 PvP 队伍。成员列表也会包含不使用 Tyria Codex 的人，与游戏列出的一致。每次打开你的应用时都会这样做，最多每半小时一次。
  • 公会活动：你创建的活动（包括每周活动）、你的回复、你提供的职责、职业和其他职责、你选择的《激战2》账号、活动开放的 Discord 身份组，以及成员添加的 Arcdps 报告链接（dps.report），连同 dps.report 为其提供的首领、结果、玩家人数和时长。
  • 通知：如果你允许，会保存你设备的通知令牌和应用语言，用于发送活动提醒。
  • Discord 服务器：如果你是公会会长并连接了 Discord 服务器：服务器 ID 和发布活动的频道、其设置（时区、语言、子区、预定活动、提醒）、用于新闻、每日成就和游戏更新的频道及可选身份组、与公会职位对应的 Discord 身份组，以及机器人向哪位 Discord 用户授予了哪些身份组，以便它只收回这些身份组。机器人无法读取消息。它会收到人们使用的命令和按钮，按下按钮时 Discord 会发送该用户的 ID 及其在该服务器中的身份组，这些仅在当时使用，不会保存。

谁能看到

  • 同样使用 Tyria Codex 的公会成员可以看到你的《激战2》账号名、你的职位以及你对公会活动的回复。
  • 他们还能看到会长的应用取回的公会内容，具体由会长选择：会长可以隐藏任何部分，而会显示谁拿了什么的金库、仓库和日志，在会长查看并确认选择之前保持隐藏。会长始终可以看到全部内容。
  • 如果你的公会连接了 Discord 服务器，频道中的所有人都能看到带有报名者名字的活动消息。
  • 你的公会之外的任何人都看不到这些内容。不使用 Tyria Codex 的人，绝不会展示给不在同一公会的任何人。

我们使用的服务

  • Supabase 在欧盟（法兰克福）托管账号数据库、登录，以及与游戏和 Discord 通信的函数。浏览器版的新闻源会经过其中一个函数，因为游戏网站不允许浏览器直接读取。
  • Google Firebase Cloud Messaging 向手机发送通知。
  • Google Fonts 提供应用的字体，因此 Google 能看到该请求。
  • Discord 负责登录，并在连接了机器人的服务器中显示消息。
  • ArenaNet 的《激战2》API 和网站提供所有游戏数据、图标和新闻。
  • dps.report 会被查询成员所添加报告链接的公开信息。
  • GitHub 托管本站和浏览器版，并能看到对它们的访问。

我们保存多久

  • 你的账号数据会一直保存，直到你删除账号。
  • 公会不属于个人，因此删除账号不会删除公会，但会长的应用取回的内容不应比会长存在得更久：当最后一位使用该应用的会长离开时，等级、每日消息、数量、成员列表、职位、金库、仓库、日志以及会长的选择都会被删除；当最后一位成员离开时，公会连同其 Discord 连接一起被删除。
  • 应用超过 30 天没有更新的公会成员身份将不再计入，90 天后会被删除。回来并重新关联即可恢复。
  • 设备的通知令牌会在你退出登录、关闭通知或令牌失效时被删除。Discord 服务器的数据会在其断开连接或其公会被删除时被删除。

删除你的账号和你的权利

在应用中，打开设置并选择“删除账号”，或者在不使用应用的情况下使用删除账号页面。你的个人资料、已关联的《激战2》账号、公会成员身份、报名、你创建的活动以及通知令牌会立即删除，且无法恢复。你也可以询问我们保存了你的哪些数据、要求更正，或反对其使用；如果你在欧盟，还可以向你所在地的数据保护机构投诉。请按下方方式联系我们。我们仅为提供你通过登录和关联所请求的内容而使用你的数据，这是我们处理数据的依据。

儿童

Tyria Codex 不面向 13 岁以下的儿童。
