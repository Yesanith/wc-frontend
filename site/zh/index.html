Tyria Codex

适用于 Android、iPhone 和浏览器的非官方《激战2》助手。

你的角色、钱包、交易所、制作、世界首领、Wizard's Vault 和世界地图，还有支持报名、职责分配的公会活动以及 Discord 机器人。

下载最新版本

在浏览器中使用

目前还没有 iPhone 应用。整个应用也可以在浏览器中运行，任何手机或电脑都可以使用。

打开 Tyria Codex

iPhone：用 Safari 打开，点按分享按钮，选择“添加到主屏幕”。之后它会像应用一样独立打开。

浏览器版没有通知、没有世界事件提醒，也没有设备上的缓存，因此加载较慢。你的 API 密钥保存在此浏览器中，只会发送到《激战2》服务器。

Tyria Codex 是粉丝项目，与 ArenaNet 或 NCSOFT 无关联，也未获得其认可。《激战2》及所有相关标志和设计均为 NCSOFT Corporation 的商标或注册商标。
