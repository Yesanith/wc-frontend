Tyria Codex

Неофициальный помощник по Guild Wars 2 для Android, iPhone и браузера.

Ваши персонажи, кошелёк, торговая площадка, ремесло, мировые боссы, Wizard's Vault и карта мира, а также события гильдии с записью, ролями и ботом для Discord.

В браузере

Приложения для iPhone пока нет. Всё приложение также работает в браузере, на любом телефоне или компьютере.

Открыть Tyria Codex

iPhone: откройте страницу в Safari, нажмите «Поделиться» и выберите На экран «Домой». После этого она открывается сама, как приложение.

В версии для браузера нет уведомлений, оповещений о мировых событиях и кэша на устройстве, поэтому она загружается медленнее. Ваш ключ API остаётся в этом браузере и отправляется только на серверы Guild Wars 2.
