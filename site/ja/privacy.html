Tyria Codexよくある質問プライバシーポリシー利用規約アカウントを削除お問い合わせ

プライバシーポリシー

最終更新日：2026年9月30日

これは翻訳です。英語版と異なる場合は、英語版が優先されます。

Tyria Codex は非公式の Guild Wars 2 コンパニオンです。広告や解析ツールはなく、あなたを追跡せず、データを広告目的で販売・共有することもありません。このページでは、何を扱うか、どこで扱うか、誰が見られるか、どのくらいの期間保持するかを説明します。Android アプリ、このサイトのブラウザ版、Discord ボットが対象です。

端末に残るもの

Guild Wars 2 の API キー、それを使って取得したゲームデータ、設定、お気に入り、ウォッチリスト、価格履歴は、端末内（ブラウザ版ではブラウザ内）にのみ保存されます。アプリは公式の Guild Wars 2 API と直接通信します。API キーが当方のサーバーに送信されることはありません。スマートフォンでは、キーはリクエストヘッダーで ArenaNet にのみ送られます。ブラウザではゲームの API でそれができないため、キーはリクエストのアドレスに含まれ、やはり ArenaNet にのみ送られます。ブラウザではキーはそのブラウザのストレージに保存され、サイトデータを消去すると削除されます。

任意の Tyria Companion アカウント

ギルドイベント、ギルド情報、Discord ボットにはアカウントが必要で、Discord でログインして作成します。以下は、作成した場合にのみ該当します。

  • Discord から：Discord のユーザー ID、名前、アバター、および Discord が提供する場合はメールアドレス。
  • Guild Wars 2 アカウント：連携するため、アプリは 10 分間有効で、アカウントと所属ギルドの読み取りだけができるトークンを作成し、そのトークンだけを送信します。アカウント名と ID、所属ギルドの名前とタグ、そこでの役職、ゲームが付与するランクを記録します。トークンはこれらの少数のリクエストにのみ使われ、保存されません。
  • ギルドのリーダーの場合：同じ 10 分間のトークンで、ゲームがギルドのリーダーにだけ見せる情報も当方のサーバーが読み取り、ギルドのために保持します。対象は、レベル、今日のメッセージ、メンバー数、各メンバーのアカウント名・ランク・加入日を含むメンバー一覧、ランクと各ランクができること、宝物庫、隠し場所、ギルドストレージ、誰が何をしたかのログ、建設済みのアップグレード、PvP チームです。メンバー一覧には、ゲームが列挙するとおり、Tyria Codex を使っていない人も含まれます。これはアプリを開くたびに、最大で 30 分に 1 回行われます。
  • ギルドイベント：作成したイベント（毎週のものを含む）、回答、提供する役割・クラス・その他の役割、選んだ Guild Wars 2 アカウント、イベントが対象とする Discord ロール、メンバーが追加した Arcdps レポートのリンク（dps.report）とそれに対して dps.report が示すボス、結果、プレイヤー数、所要時間。
  • 通知：許可した場合、端末の通知トークンとアプリの言語。イベントのリマインダーを送るために使います。
  • Discord サーバー：ギルドのリーダーとして Discord サーバーを接続した場合、サーバー ID とイベントの投稿先チャンネル、その設定（タイムゾーン、言語、スレッド、スケジュールイベント、リマインダー）、ニュース・デイリーアチーブメント・ゲームのアップデート用のチャンネルと任意のロール、ギルドのランクに対応付けた Discord ロール、そしてボットが Discord のどのユーザーにどのロールを付与したか（付与したものだけを取り消せるようにするため）。ボットはメッセージを読めません。人々が使うコマンドとボタンを受け取り、ボタンを押すと Discord がその人の ID とそのサーバーでのロールを送ってきますが、それはその場限りで使われ、保存されません。

誰が見られるか

  • Tyria Codex も使っているギルドのメンバーは、あなたの Guild Wars 2 アカウント名、ランク、ギルドのイベントへの回答を見られます。
  • リーダーのアプリが取り込んだギルドの情報も、リーダーの選択に従って見られます。リーダーはどの部分も非表示にでき、誰が何を取ったかが分かる宝物庫・隠し場所・ログは、リーダーが選択を確認して確定するまで非表示のままです。リーダーは常にすべてを見られます。
  • ギルドが Discord サーバーを接続している場合、そのチャンネルにいる全員が、参加登録した人の名前付きでイベントのメッセージを見られます。
  • ギルド以外の人がこれらを見ることはありません。Tyria Codex を使っていない人は、同じギルドにいない人には決して表示されません。

利用しているサービス

  • Supabase は、アカウントのデータベース、ログイン、ゲームおよび Discord と通信する関数を、欧州連合（フランクフルト）でホストします。ゲームのサイトがブラウザからの読み取りを許可していないため、ブラウザ版のニュースフィードはこれらの関数のひとつを経由します。
  • Google Firebase Cloud Messaging は、スマートフォンに通知を届けます。
  • Google Fonts はアプリの書体を提供するため、Google はそのリクエストを確認できます。
  • Discord はログインを処理し、ボットを接続したサーバーにメッセージを表示します。
  • ArenaNet の Guild Wars 2 API とサイトが、すべてのゲームデータ、アイコン、ニュースを提供します。
  • dps.report には、メンバーが追加したレポートリンクの公開情報を問い合わせます。
  • GitHub はこのサイトとブラウザ版をホストし、それらへのアクセスを確認できます。

保持期間

  • アカウントのデータは、アカウントを削除するまで保持されます。
  • ギルドは個人のものではないため、アカウントを削除してもギルドは削除されません。ただし、リーダーのアプリが取り込んだものはリーダーより長く残るべきではありません。アプリを使う最後のリーダーがいなくなると、レベル、今日のメッセージ、数値、メンバー一覧、ランク、宝物庫、隠し場所、ログ、リーダーの選択が削除され、最後のメンバーがいなくなるとギルドは Discord の接続ごと削除されます。
  • アプリが 30 日間更新していないギルドへの所属は数えられなくなり、90 日後に削除されます。戻って再度連携すると復元されます。
  • 端末の通知トークンは、ログアウトしたとき、通知をオフにしたとき、またはトークンが使えなくなったときに削除されます。Discord サーバーのデータは、接続が解除されたとき、またはそのギルドが削除されたときに削除されます。

アカウントの削除とあなたの権利

アプリでは、設定を開き「アカウントを削除」を選ぶか、アプリを使わずにアカウント削除ページを使ってください。プロフィール、連携した Guild Wars 2 アカウント、ギルドへの所属、参加登録、作成したイベント、通知トークンは直ちに削除され、元に戻せません。また、当方が保有しているあなたの情報の開示、訂正、利用への異議を求めることができ、欧州連合にお住まいの場合は、データ保護当局に苦情を申し立てることもできます。下記の方法でご連絡ください。データは、ログインと連携によってあなたが求めたものを提供するためにのみ使用します。これが取り扱いの根拠です。

子ども

Tyria Codex は 13 歳未満の子どもを対象としていません。
