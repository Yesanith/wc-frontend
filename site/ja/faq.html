よくある質問

Tyria Codex とは何ですか？

非公式の Guild Wars 2 コンパニオンです。キャラクター、ウォレット、トレーディングポスト、クラフト、ワールドボス、Wizard's Vault、ワールドマップに加え、参加登録付きのギルドイベントと Discord ボットが使えます。ファンによるプロジェクトで、無料、広告なしです。

どこで使えますか？

Android ではアプリとして、どのスマートフォンやパソコンでもブラウザからこのサイトのアプリページで使えます。iPhone 向けアプリはまだありません。ブラウザ版を Safari で開き、共有をタップして「ホーム画面に追加」を選ぶと、アプリのように開きます。ブラウザ版には通知とワールドイベントのアラートがありません。

API キーは必要ですか？ どの権限が必要ですか？

ゲームのデータは、account.arena.net で作成するご自身の Guild Wars 2 API キーから取得します。見たい項目にチェックを入れてください。account は常に必要で、characters、inventories、wallet、tradingpost、guilds がそれぞれの機能を有効にします。キーがなくても、アカウントに関係しない機能はすべて使えます。

API キーは安全ですか？

キーは端末内（ブラウザ版ではブラウザ内）に保存され、Guild Wars 2 のサーバーにのみ送信されます。当方のサーバーには一切送信されません。プライバシーポリシーをご覧ください。キーは読み取り専用で、account.arena.net でいつでも削除できます。

Tyria Companion のアカウントは必要ですか？

いいえ、任意です。ギルドイベント、ギルド情報、Discord ボットを使う場合に必要です。Discord でログインして作成し、設定またはアカウント削除ページからいつでも削除できます。

Guild Wars 2 アカウントを連携すると何が起こりますか？

アプリは 10 分間有効なトークンを作成し、それだけを送信します。キーは送りません。アカウント名、所属ギルド、そこでのランクを記録します。ギルドのリーダーの場合、同じトークンにより、ゲームがリーダーにだけ見せる情報を当方のサーバーが読み取り、ギルドメンバーがアプリで見られるようになります。

ギルドの宝物庫・隠し場所・ログが見られないのはなぜですか？

ゲームはそれらをギルドのリーダーにだけ見せます。リーダーが Tyria Companion を使い、許可すると、メンバーはここで見られます。リーダーがアプリを一度開くとギルドのデータが取り込まれ、メンバーに見せる内容を選べます。どの部分も非表示にできます。誰が何を取ったかが分かる宝物庫・隠し場所・ログは、リーダーが選択を確定するまで非表示のままです。

「リーダーがまだ共有していません」と表示されます。

リーダーが連携後にアプリを開いていない、ゲームが一部を拒否した、またはリーダーが非表示にした、のいずれかです。リーダーにアプリを開いてもらい、ギルドのページにある目のボタンを確認してもらってください。

誰がオフィサーになりますか？

ゲームが決めます。招待・昇格・追放、またはランクの編集ができるランクがオフィサーになり、オフィサーはイベントを作成・管理できます。手動で任命される人はいません。アプリにはギルドが付けたランク名（例：Raid Lead）が表示されます。

Discord ボットはどう追加しますか？

サーバーに招待し、「サーバー管理」権限を持つギルドリーダーが、イベントを表示したいチャンネルで、ギルドのタグまたは名前を付けて /tyria connect を実行します。ボットにはチャンネルを見て書き込む権限が必要です。スレッド、スケジュールイベント、ロール、リマインダーには対応する権限が必要で、足りないものは /tyria status が教えてくれます。

ボットには何ができますか？

/event create と /event weekly でイベントを作成し、プレイヤーはボタンでクラスと役割を選んで参加登録します。/event report は Arcdps のレポートリンクを追加します。/tyria settings はスレッド、Discord イベント、リマインダーを設定します。/tyria notify はデイリーアチーブメント、ニュース、ゲームのアップデートを投稿します。/tyria roles と /tyria rankrole はギルドのランクに応じた Discord ロールを付与します。ボットはメッセージを読めません。

Discord ロールはギルドのランクにどう連動しますか？

/tyria roles ranks:true を実行します。ボットはギルドの各ランクに対して、権限のない Discord ロールを 1 つ作成し、そのランクを持つ人に付与します。リーダーのアプリがランクを取り込んだ時点で始まり、それまではメンバー・オフィサー・リーダーのロールが適用されます。

ブラウザで足りない機能があるのはなぜですか？

ブラウザ版はスマートフォンの通知、ワールドイベントのアラート、端末上のキャッシュを使えないため、読み込みが遅くなります。ほかに動かないものがあれば、お知らせください。

データを削除するには？

設定から「アカウントを削除」を選ぶか、アカウント削除ページを使います。プロフィール、連携アカウント、所属、参加登録、作成したイベントはすぐに削除されます。ギルドのリーダーが取り込んだデータは、アプリを使う最後のリーダーがいなくなると削除されます。

ArenaNet と関係がありますか？

いいえ。ファンによるプロジェクトです。Guild Wars 2 とそのロゴおよびデザインは NCSOFT Corporation の商標です。

問題が起きました。どこに報告すればよいですか？

GitHub で Issue を作成し、行った操作と見た内容を書いてください。スクリーンショットがあると助かります。API キーは絶対に投稿しないでください。
