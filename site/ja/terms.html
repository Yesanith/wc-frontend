利用規約

最終更新日：2026年9月30日

これは翻訳です。英語版と異なる場合は、英語版が優先されます。

この規約は、あなたと、Tyria Codex（Android アプリ、このサイトのブラウザ版、Discord ボット）を運営する人との間のものです。これらを利用することで、この規約に同意したものとみなされます。同意しない場合は、利用しないでください。

これは何か

Tyria Codex は、Guild Wars 2 向けの非公式で無料のファンプロジェクトです。ArenaNet や NCSOFT とは提携しておらず、その承認も受けていません。Guild Wars 2 および関連するすべてのロゴとデザインは、NCSOFT Corporation の商標または登録商標です。ゲームのデータと画像は ArenaNet の公開 Guild Wars 2 API から取得し、その規約が認める範囲で使用しています。Tyria Codex を利用しても、ArenaNet、Discord、その他に対するあなたの権利や義務は変わりません。

利用できる人

13 歳以上であり、お住まいの地域でこの規約に同意できる年齢に達している必要があります。Guild Wars 2、Discord、および併用するその他のサービスの規約に従う必要があります。

アカウントと API キー

  • Tyria Companion のアカウントは任意で、Discord でログインして作成します。アカウントを通じて起きることについては、あなたが責任を負います。
  • API キーはあなたのものです。他人に教えず、与えたい権限だけを持つキーを使い、漏えいした可能性があれば account.arena.net で無効にしてください。当方がキーをお尋ねすることはありません。
  • 連携できるのは、あなた自身の Guild Wars 2 アカウントのみです。

ギルドと共有する内容

  • アプリを使うギルドのリーダーは、ゲームがリーダーにだけ見せるギルドのデータを当方のサーバーが読み取り保持することを許可し、リーダーの選択に従って、アプリを使うギルドメンバーに表示します。リーダーはこれに同意し、表示すると選んだ内容に責任を負います。何をどのくらい保持するかは、プライバシーポリシーに記載しています。
  • 代表する権限のないギルドのために、アカウントを連携したり Discord サーバーを接続したりしないでください。
  • 追加したギルドイベント、説明、レポートは、ギルドに、また Discord サーバーが接続されている場合はそのチャンネルに表示されます。違法、憎悪的、嫌がらせ、誤解を招く内容や、他人の個人情報を投稿しないでください。

してはいけないこと

  • 人への嫌がらせやなりすまし、スパム、ゲームや Discord の規則に違反する目的で利用すること。
  • 自分のものではないデータにアクセスしようとすること、サービスに過負荷をかけたり妨害したりすること、その制限を回避しようとすること。
  • データを自動的に収集すること、転売すること、または許可なく、同じことを他人向けに行うものを作るために利用すること。

コンテンツと削除

あなたが作成したものはあなたのものです。アプリの動作として、それを保存し、対象となる人に表示することを許可するものとします。この規約に違反する、またはサービスや他の人に害を与えるコンテンツやアカウントを削除することがあり、そうした Discord サーバーの接続を解除することがあります。アカウントはいつでも削除できます。アカウント削除ページをご覧ください。

提供状況と変更

1 人が余暇に運営しており、Guild Wars 2 API、Discord、その他当方が管理できないサービスに依存しています。遅い、誤っている、利用できない、予告なく変更されることがあり、サービスやその機能を終了することがあります。ゲームのデータの正確さは、ゲームの API の正確さに依存します。
